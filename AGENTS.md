# AGENTS.md

## Scope
These instructions apply to the entire repository.

## Repository intent
This repository is for the browser extension code and its deployment workflow.

## Hard rules for future changes
- Keep the extension area limited to extension runtime/distribution files only.
- Do **not** add tests, mocks, sample data, legacy app code, or unrelated tooling inside the extension area.
- Treat `legacy/` (or any future migrated equivalent, such as `references/`) as **reference-only** content.
- Reference code must never be used as a runtime/build dependency for the extension.
- If a feature requires copying logic from reference projects, port only the required logic into extension-owned files.
- Keep packaging/deployment focused on extension artifacts (zip generated by build/CI), not committed binaries.

## PR expectations
- Keep PRs scoped to extension functionality and extension deployment pipeline.
- Avoid mixing repository reorganization with functional changes unless explicitly requested.
